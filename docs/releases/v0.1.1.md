MnemoCode 0.1.1 is the last release of the TypeScript version. This version is no longer developed and gets fixes for critical defects only. MnemoCode continues in Rust: [hobby-eng/mnemocode](https://github.com/hobby-eng/mnemocode).

The changes fix problems found while testing 0.1.0 and in the audit AUD-039:

- Encoding a seed phrase as English words or word numbers now needs a Seedshift, because without one these forms are the seed phrase itself.
- Saved QR images have a wider blank border, so cameras find the code more easily.
- Separate card files are named by number only, such as `01.pdf`, so a folder listing shows no code.
- Card text that does not fit, a Bitcoin address that the chosen profiles cannot produce, and options that would be ignored are refused before you type any secret.
- A result that cannot be written, for example to a full disk, ends with an error instead of success.
- The program wipes more of its working copies of shares, and the SSKR engine wipes all the memory it frees.

If you use MnemoCode as a library, some error codes have new names and some inputs are now refused. [CHANGELOG.md](https://github.com/hobby-eng/mnemocode_typescript/blob/v0.1.1/CHANGELOG.md) lists every change.

Check the download before you run it, as [Download verification](https://github.com/hobby-eng/mnemocode_typescript/blob/v0.1.1/docs/CLI.md#download-verification) explains.
